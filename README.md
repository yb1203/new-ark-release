# New-ark

New-ark 是一套可自托管的个人导航主页。把常用网站、分组、页面和访问权限集中管理，在 NAS 上即可拥有自己的快捷入口。

本仓库仅用于发布飞牛 NAS 安装包（FPK）和使用说明，不包含源码。

## 首页效果

![New-ark 深色首页](assets/home-dark.png)

## 主要功能

- 常用网站卡片与分组管理，支持多页面导航
- 内网优先访问，失败后自动尝试互联网地址
- 浅色 / 深色主题、背景图片与外观设置
- 图标上传、在线获取、图库选择和裁剪调整
- 访客访问与访问权限控制，分享链接随当前访问地址自动适配
- 用户、注册申请、页面权限和备份还原管理

## 安装方法

1. 在 [Releases](https://github.com/yb1203/new-ark-release/releases) 下载最新的 `.fpk` 安装包。
2. 打开飞牛 NAS 的应用中心，选择手动安装并导入安装包。
3. 按安装向导填写运行端口，完成后从桌面图标或 `http://NAS地址:端口` 打开。
